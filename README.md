**Nostra E-Commerce Website**

**Description:**

Nostra is a fully responsive e-commerce website built to provide users with an intuitive shopping experience.
The platform offers a range of products, an easy-to-navigate interface, and seamless interactions, making it convenient for users to browse, add items to their cart, and place orders.
The website is designed using modern web technologies and is hosted for public access.

**Key Features:**

Product Listings: Browse through a collection of products across different categories.
Cart Management: Add, view, and remove products from the cart before checkout.
User Feedback Integration: Users can send feedback through an integrated form powered by Formspree.
Responsive Design: The website is optimized for all device sizes, providing a smooth experience on both desktop and mobile platforms.

**Technologies Used:**

HTML5 for structured content.
CSS3 for modern styling and layout.
JavaScript for interactivity and functionality.
Bootstrap for a responsive design.
Formspree for handling user feedback through emails.
